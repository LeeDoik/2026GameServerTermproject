# NotebookLM 발표 슬라이드 제작 가이드 + 프롬프트

대상: `발표_가이드.md` 기반 5분 발표 슬라이드 6장 생성
도구: Google NotebookLM (notebooklm.google.com)

> ⚠️ NotebookLM은 PPTX를 직접 export 하지 않는다. **슬라이드별 텍스트(제목·불릿·발표 대본·비주얼 제안)**를 생성시킨 뒤, Google Slides / PowerPoint / Gamma 에 옮겨 붙이는 흐름이다. 그래서 아래 프롬프트는 "그대로 슬라이드에 박을 수 있는 형태"로 출력하도록 설계했다.

---

## STEP 1 — 소스 업로드 (Notebook 생성 → Sources)

이 순서로 올린다. **보고서가 1순위 근거**, 발표_가이드가 슬라이드 골격이다.

| 우선순위 | 파일 | 역할 |
|---|---|---|
| ★1 | `게임서버_텀프로젝트_보고서.docx` | 정확한 숫자·용어·아키텍처 근거 (NotebookLM이 인용) |
| ★2 | `발표_가이드.md` | 6장 슬라이드 골격 + 핵심 메시지 |
| 3 | `Aetheria_Online_MMORPG_기획서.pdf` | 게임 콘텐츠(바이옴·스킬·퀘스트·보스) 디테일 |
| 4 | `추가 기능 기획서.docx` | 파티·아이템 등 추가 기능 |

> docx는 NotebookLM에 직접 업로드 가능. 안 되면 PDF로 변환해서 올린다. (`보고서`는 가능하면 PDF로도 같이.)

설정 팁:
- Notebook **언어를 한국어**로 (우상단 설정 → Output language → 한국어). 안 하면 영어로 답할 수 있다.
- 소스 업로드 후 한 번 "이 보고서의 핵심 성능 수치를 정리해줘"로 가볍게 질문해 **인덱싱·인용이 되는지 확인**한다.

---

## STEP 2 — 메인 프롬프트 (채팅창에 그대로 붙여넣기)

아래 전체를 복사해 NotebookLM 채팅에 붙여넣는다. 슬라이드 6장이 한 번에 나온다.

```text
너는 게임서버 텀프로젝트 발표 슬라이드를 만드는 발표 코치다.
업로드된 보고서/기획서/발표_가이드를 근거로, 아래 6장 구조를 그대로 따라
"발표용 슬라이드 텍스트"를 생성해라. 발표 시간은 슬라이드 1장당 약 50초(총 5분)다.

[절대 규칙]
- 발표 콘셉트: "게임 콘텐츠 나열이 아니라 서버 엔지니어링으로 승부한다."
- 다음 3개 숫자는 반드시 슬라이드와 대본에 등장: ① 20만 NPC ② 단일 머신 3,462 CCU @ 0~1ms ③ 핵심 서버 모듈 전부 자체 구현.
- 수치·용어는 반드시 보고서에서 가져와 정확히 써라. 보고서에 없는 숫자는 지어내지 마라.
- 슬라이드 본문은 "문장"이 아니라 "키워드 불릿"으로. 한 불릿 12자 내외.
- 청중은 게임서버 프로그래밍 담당 교수. 표절·자체구현 여부와 성능을 가장 본다.

[각 슬라이드 출력 형식]
■ 슬라이드 N: <제목 한 줄>
- 불릿: (3~4개, 키워드만)
- 발표 대본: (실제로 입으로 말할 ~50초 분량 구어체 2~4문장. 숫자는 강조)
- 비주얼 제안: (다이어그램/표/아이콘 등 이 장에 들어갈 시각자료 1줄)

[6장 구조]
1. 타이틀 + 성과 한 줄
   - "Aetheria Online — Win32 IOCP MMORPG"
   - 20만 NPC / 단일 머신 3,462 CCU @ 0~1ms / 핵심 서버 모듈 전부 자체 구현 을 첫 화면에 박는다.
2. 통합 IOCP 아키텍처
   - 네트워크 I/O · 타이머 만기 · DB 완료를 '하나의 IOCP'로 통합
   - 모든 게임 상태 변경이 워커 컨텍스트에서만 발생 → 동기화 규약 단일화
3. 20만 NPC를 버티는 3대 비결
   - ① 섹터 기반 AOI(9섹터만 검사) ② Lazy AI(플레이어 근처만 활성, 활성 수=동접 비례) ③ 워커 로컬 Lua VM(thread_local, AI 핫패스 락 0)
4. 최적화 여정 (스토리)
   - 3,000 CCU 벽 → 원인 진단(단일 Lua락·단일 타이머·전역 송신풀)
   - Phase1 병렬화(워커VM·8샤드 타이머·8샤드 송신풀) + Phase2A 송신 코얼레싱
   - 3,462 @ 0~1ms로 벽 해소. (전/후 비교를 화살표로)
5. 자체 구현 (표절 방지 정면돌파)
   - 제공된 protocol_2026.h만 사용
   - IOCP 래퍼 / 패킷조립(Length-Prefix + 자체 RingBuffer) / 타이머(Min-Heap) / DB 비동기 Job Queue / Lua 바인딩 — 전부 scratch부터
6. 게임 콘텐츠 한눈에 + 채점 매핑
   - 4바이옴 · 스킬3종 · 파티 · 아이템/장비 · 연쇄퀘스트 · 2페이즈 보스 (아이콘+한 줄씩)
   - 마무리 멘트: "동작은 곧 시연 영상으로 보여드리겠습니다"로 시연 전환

먼저 6장을 위 형식으로 출력해라. 마지막에 "발표 시 입으로 강조할 숫자 3개"를 한 줄로 다시 정리해라.
```

## STEP 3 — 보조 프롬프트 (필요할 때 추가로)

메인 결과를 받은 뒤, 부족한 부분만 골라 추가 요청한다.

**① 슬라이드별 발표 대본만 다듬기 (5분 타임 체크)**
```text
방금 만든 6장의 '발표 대본'만 모아서, 전체를 소리 내어 읽었을 때 4분 30초~5분이 되도록 분량을 조절해줘. 슬라이드당 예상 소요 시간(초)을 옆에 표기하고, 너무 긴 문장은 끊어서 호흡 표시(/)를 넣어줘.
```

**② Q&A 대비 슬라이드 (백업용, 발표엔 안 띄움)**
```text
발표_가이드의 '예상 질문 & 답변'을 근거로, 질의응답 백업 슬라이드 6장을 만들어줘. 각 장은 [예상 질문]을 제목으로, 답변은 30초 분량 키워드 불릿으로. 특히 'IOCP 직접 짰나' '5,000 CCU 못 채운 거 아닌가' '20만 NPC 다 돌리나' 세 개는 가장 앞에.
```

**③ 한 장 요약 / 썸네일 카피**
```text
이 프로젝트를 한 문장으로 설명하는 발표 첫 화면 헤드라인 후보 3개를 만들어줘. 각 후보는 20자 이내이고 숫자(20만 NPC, 3,462 CCU, 자체 구현) 중 하나 이상을 포함해야 해.
```

**④ 영어 발표가 필요하면**
```text
위 6장 슬라이드의 불릿과 대본을 영어로도 만들어줘. 기술 용어(IOCP, AOI, RingBuffer, Min-Heap, thread_local)는 원어 유지.
```

## STEP 4 — 슬라이드로 옮기기

NotebookLM 출력을 실제 슬라이드로 만드는 3가지 경로:

1. **Gamma / 감마(gamma.app) 추천** — NotebookLM이 뽑은 "■ 슬라이드 N + 불릿"을 통째로 붙여넣으면 디자인까지 자동 생성. 가장 빠름.
2. **Google Slides + 확장(예: "Slides from text")** — 불릿 텍스트를 장별로 자동 변환.
3. **수동(PowerPoint)** — 6장이라 손으로 해도 30분. 불릿/대본/비주얼 제안이 이미 나와 있어 빈칸 채우기 수준.

> 비주얼 핵심 2장은 직접 그려라(자동생성 한계):
> - **슬라이드 2(아키텍처)**: 보고서 3장 다이어그램 = 네트워크/타이머/DB → [하나의 IOCP] → 워커 박스. 보고서에서 캡처해 넣는 게 가장 강력.
> - **슬라이드 4(최적화 여정)**: `3,000 벽 → [Phase1+2A] → 3,462 @ 0~1ms` 화살표 전/후 비교.
