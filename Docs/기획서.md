# Aetheria Online - 추가 기능 상세 기획서 (Additional Features Specification)

본 문서는 **Aetheria Online** 서버의 핵심 기능 외에, 가산점 확보 및 게임의 완성도를 높이기 위해 설계된 추가 구현 요소들에 대한 상세 명세를 다룹니다.

---

## 1. 아이템 및 인벤토리 시스템 (Item & Inventory)
전통적인 MMORPG의 성장을 지원하기 위한 핵심 시스템입니다.

*   **아이템 구조체 설계:** ItemID, Type(소비/장비/재료), 스택 가능 수량, 능력치(ATK/DEF), 가격 정보를 포함하는 데이터베이스 구축.
*   **슬롯 기반 인벤토리:** 플레이어당 30~40칸의 그리드형 인벤토리 관리. 서버 측에서 아이템 이동(Swap), 버리기, 사용 패킷 엄격 검증.
*   **장비 시스템:** 무기, 방어구 장착 시 플레이어 스탯에 즉시 반영. 장착 중인 아이템 정보는 DB에 저장되어 재접속 시 유지.
*   **필드 드랍:** NPC 사망 시 루팅 테이블에 따른 확률적 드랍. 아이템 소유권 설정(최초 타격자 또는 최대 대미지 기여자) 및 30초 후 소멸 타이머 처리.

## 2. 파티 및 협력 시스템 (Party System)
플레이어 간 상호작용과 협력 플레이를 유도합니다.

*   **파티 관리 로직:** 최대 4인 파티 구성. 초대(Invite), 수락(Accept), 추방(Kick), 방장 위임 기능을 포함하는 관리 시스템.
*   **실시간 상태 동기화:** 같은 맵에 있는 파티원의 HP/MP 및 위치 정보를 실시간으로 패킷 전송하여 UI에 표시.
*   **경험치 및 골드 분배:** 몬스터 처치 시 일정 범위 내의 파티원에게 경험치 균등 분배(1/N) 및 파티 보너스(예: +10%) 적용.

## 3. 퀘스트 및 업적 시스템 (Quest System)
유저에게 지속적인 목표를 제시합니다.

*   **퀘스트 유형 세분화:**
    *   **사냥(Slay):** 특정 몬스터 N마리 처치.
    *   **수집(Fetch):** 특정 아이템 N개 모으기.
    *   **전달(Talk):** 특정 NPC와 대화하여 정보 전달.
*   **퀘스트 상태 관리:** 수락 가능, 진행 중, 완료 가능, 보상 수령 완료 상태를 서버와 DB에서 관리.
*   **보상 시스템:** 퀘스트 완료 시 경험치, 골드, 특정 퀘스트 전용 아이템 지급 로직.

## 4. 스킬 및 상태 이상 시스템 (Skill & Buff)
전투의 전략적 깊이를 더합니다.

*   **캐릭터 직업(Class) 시스템:** 플레이어 생성 또는 로그인 시 직업 선택 (전사, 마법사, 사제).
*   **자원 시스템:** 직업별로 특화된 자원 사용(HP/MP).
*   **직업별 상세 스킬 세트:**

| 직업 | 스킬명 | 타입 | 효과 및 소모 자원 |
| :--- | :--- | :--- | :--- |
| **전사** | **강격** | Active | 단일 대상 1.5배 대미지. MP 5 소모. |
| | **위협** | Buff | 15초간 주변 몬스터의 공격력을 10% 감소. MP 20 소모. |
| | **대지 분쇄** | AoE | 5x5 범위 적 대미지 및 1초 기절. MP 40 소모. |
| **마법사** | **화염 화살** | Active | 원거리 단일 대상 마법 대미지. MP 15 소모. |
| | **운석 낙하** | AoE | 3x3 강력한 화염 대미지 + 연소 상태 이상. MP 60 소모. |
| | **마력 방패** | Buff | 30초간 받는 대미지의 30%를 MP로 대신 소모. MP 30 소모. |
| **사제** | **치유** | Active | 단일 대상 HP 20% 회복. MP 20 소모. |
| | **신의 권능** | Buff | 60초간 파티 전체의 공격력을 15% 증가. MP 50 소모. |
| | **성스러운 대지** | AoE/Heal | 10초간 해당 범위 내 아군 HP 지속 회복. MP 80 소모. |

*   **상태 이상(Status Effect) 연동:** 연소(지속 대미지), 기절(행동 불가), 축복(스탯 상승) 등.

## 5. 경제 및 거래 시스템 (Economy)
재화의 순환과 유저 간의 자유로운 거래를 지원합니다.

*   **화폐 시스템:** '골드(Gold)' 재화 추가. 몬스터 처치, 퀘스트 보상, 아이템 판매를 통해 획득.
*   **NPC 상점:** 아이템 매입/매각 시스템. 상점별 물품 리스트 JSON 로드.
*   **1:1 개인 거래:** 플레이어 간의 안전한 거래 창 시스템. 양측의 'Lock' 상태 확인 후 최종 승인 시 아이템 및 골드 원자적(Atomic) 교환 처리.

## 6. 실시간 서버 모니터링 및 관리자 시스템 (Monitoring & Admin)
서버 안정성과 운영 편의성을 확보합니다.

*   **서버 상태 대시보드:** CCU, PPS, Uptime 등을 실시간으로 콘솔에 출력.
*   **GM 커맨드 시스템:** 채팅창 관리자 명령어(Prefix: '/') 구현. (Kick, NPC 스폰, 파라미터 조정 등)

## 7. 상세 게임 밸런스 설계 (Detailed Game Balance Design)

### 7.1 캐릭터 성장 및 경험치 곡선
*   **경험치 요구량 공식:** `Next_Level_EXP = (Current_Level^3) * 50 + (Current_Level * 100)`
*   **사망 페널티:** 전체 경험치의 5% 감소.
*   **최고 레벨:** 99.

### 7.2 전투 메커니즘 공식
*   **최종 데미지 공식:** `Final_Damage = Attacker_ATK * (100 / (100 + Defender_DEF))`
*   **치명타:** 확률 5%, 발동 시 150% 데미지.

### 7.3 직업별 상세 스탯 가이드
| 직업 | HP 성장 | MP 성장 | 주요 공격 스탯 |
| :--- | :--- | :--- | :--- |
| **전사** | +50 | +10 | STR (물리) |
| **마법사** | +20 | +40 | INT (마법) |
| **사제** | +35 | +30 | MND (신성) |

### 7.4 경제 밸런스 정책
*   **골드 생성:** 몬스터 처치 및 퀘스트 보상.
*   **골드 회수:** 소모품 구매, 사망 부활 비용, 장비 강화 시스템.
