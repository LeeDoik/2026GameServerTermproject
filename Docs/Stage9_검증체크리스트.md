  - 또는 서버 부팅 로그에 `[Quest] Loaded 3 quest defs.` 가 떠야 정상 (안 뜨면 data 경로 문제)

## 1. 서버 부팅 확인

- [ ] 서버 실행 → 콘솔에 아래가 모두 보이는지:
  - [ ] `[Item] Loaded 8 item defs.`
  - [ ] `[Quest] Loaded 3 quest defs.`  ← 퀘스트 핵심
  - [ ] `[NpcSpawner] Spawned 200000 NPCs`
  - [ ] `[Db] JSON backend root: ...`
  - [ ] 빨간 에러/크래시 없음

## 2. 퀘스트 수락 (대화)

- [ ] 클라 실행 → 캐릭터 이름 입력 후 접속 (마을에서 시작)
- [ ] **장로**에게 이동: 마을 **북서쪽** NPC(머리 위 `!`), 좌표 약 (985, 985)
- [ ] 장로 옆(3칸 이내)에서 **`T`** 키 → 화면 하단에 **대화창**이 떠야 함
  - [ ] "[새 퀘스트] 슬라임 퇴치" + 설명 + "[Y] 수락 / [Esc] 닫기"
- [ ] **`Y`** → 채팅창에 `[Quest] '슬라임 퇴치' 0/3` 류 메시지
- [ ] **`J`** → 우측에 퀘스트 로그 패널, "슬라임 퇴치 0/3" 표시
- [ ] (확인) 장로에게서 **멀리** 떨어진 곳에서 `T` → "장로 근처에서…" 안내만 뜨고 대화창 안 열림

## 3. 슬레이 (처치 카운트)

- [ ] SW 초원(좌상단/맵 왼쪽 아래 지역)으로 이동 — 숫자키 `3`(좌로 텔레포트) 등 활용
- [ ] **Slime** 처치 (`A` 공격 또는 `Q`/`W` 스킬)
  - [ ] 처치할 때마다 진행도 갱신: 채팅 `[Quest] '슬라임 퇴치' 1/3 → 2/3 → 3/3`
  - [ ] `J` 로그 패널 숫자도 같이 증가
- [ ] 3마리 채우면: 채팅 `목표 달성 — 장로에게 보고하세요`, 로그에 `[보고 가능]`
- [ ] (타겟 매칭 확인) **다른 종족**(예: Rat, Goblin)을 처치해도 "슬라임 퇴치" 카운트는 **안 올라가야** 정상

## 4. 보상 수령 (turn-in) + 연쇄

- [ ] 마을 장로로 복귀 → 머리 위 마커가 **`?`(금색)** 으로 바뀌었는지
- [ ] 장로 옆에서 **`T`** → 대화창 "목표 달성! / [Y] 보상 받기"
- [ ] **`Y`** → 보상 지급 확인:
  - [ ] 채팅 `[Quest] '슬라임 퇴치' 완료!` + "Quest complete! Rewards granted."
  - [ ] **EXP 증가** (하단 EXP 바)
  - [ ] **`I`** 인벤토리 열어 **HealthPotion x2** 들어왔는지
- [ ] **연쇄 확인**: 다시 장로에게 `T` → **다음 퀘스트 "쥐 사냥"(q2)** 이 Offer로 떠야 함 (선행 q1 완료 덕분)
  - [ ] (참고) q2 = Rat 5마리, q3 = Goblin 5마리 → RustySword

## 키 요약 (Stage 9 신규)

| 키 | 동작 |
|---|---|
| `T` | 장로 근처에서 대화 (수락/보고) |
| `J` | 퀘스트 로그 패널 토글 |
| `Y` | 대화창에서 수락 / 보상 받기 |
| `Esc` | 대화창 닫기 |

## 문제가 생기면 체크할 곳

- 대화창이 안 뜸 → 장로(985,985) 3칸 이내인지 / 서버에 `[Quest] Loaded 3 quest defs.` 떴는지
- 처치해도 카운트 안 오름 → npc_spawn.txt의 종족명과 quests.txt의 `target_species` 철자 일치 여부 (예: `Slime`)
- 재로그인 시 초기화됨 → data/players/<이름>.json에 `"quests"` 키가 저장되는지 (저장 주기 30초 또는 정상 로그아웃 필요)
