# Aetheria Online — 퀘스트 카탈로그 (Stage 9)
# 형식: id  prereq  giver  target_species  count  reward_exp  reward_item  reward_qty
#   id             : 퀘스트 고유 ID (1부터)
#   prereq         : 선행 퀘스트 ID (-1 = 없음). 연쇄(chain) 구성용
#   giver          : 퀘스트를 주는 마을 NPC 인덱스 (0 = 장로)
#   target_species : 처치 대상 종족 접두사. data/npc_spawn.txt의 name 컬럼과 일치
#   count          : 처치 목표 수
#   reward_exp     : 완료 보상 경험치
#   reward_item    : 완료 보상 아이템 ID (-1 = 없음, data/items.txt 참조)
#   reward_qty     : 보상 아이템 개수
#
# 장로(0)에서 시작하는 3단 연쇄: 슬라임 → 쥐 → 고블린

1  -1  0  Slime    3   50    1   2    # 슬라임 퇴치 → HealthPotion x2
2   1  0  Rat      5   120   1   3    # 쥐 사냥 → HealthPotion x3
3   2  0  Goblin   5   300   10  1    # 고블린 토벌 → RustySword x1
