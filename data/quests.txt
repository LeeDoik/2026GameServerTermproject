# Aetheria Online — 퀘스트 카탈로그 (Stage 9)
# 형식: id  prereq  giver  target_species  count  reward_exp  reward_item  reward_qty
#   id             : 퀘스트 고유 ID (1부터)
#   prereq         : 선행 퀘스트 ID (-1 = 없음). 연쇄(chain) 구성용
#   giver          : 퀘스트를 주는 마을 NPC 인덱스 (0 = 장로)
#   target_species : 처치 대상 종족 접두사. data/npc_spawn.txt의 name 컬럼과 일치
#   count          : 처치 목표 수
#   reward_exp     : 완료 보상 경험치
#   reward_item    : 완료 보상 아이템 ID (-1 = 없음, data/items.txt 참조)
#   reward_qty     : 보상 아이템 개수
#
# 장로(0)에서 시작하는 4단 연쇄: 구역별 보스 1마리씩 처치 → 장로에게 보고(말걸기) → 완료
#   SW 초원 GrassBoss → SE 숲 ForestBoss → NE 사막 DesertBoss → NW 설원 IceBoss

1  -1  0  GrassBoss   1   500     1   3    # SW 초원 보스(Slime King) 처치 → HealthPotion x3

3   2  0  DesertBoss  1   4000    1   5    # NE 사막 보스(Golden Dragon) 처치 → HealthPotion x5
4   3  0  IceBoss     1   12000   10  1    # NW 설원 보스(Cerebov) 처치 → RustySword x1
